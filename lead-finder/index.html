Kivabe use korben

  1. List theke city ar business type select korun. Select korlei search shuru hoy. List e na thakle "Other city" diye likhe Find leads chapun.
  2. Tool ta map theke business ber kore, tarpor protiti website Google PageSpeed diye check kore.
  3. Beshi score = beshi problem = bhalo client. Hot lead gulo age contact korun.
  4. Prothome "Your details, prices" e nijer naam, WhatsApp ar package er dam din. Report ar email e eguloi boshe.

Client convince korar dhap

  1. First email: oder 3 ta ashol problem bolun, free report offer korun. Link ba attachment deben na.
  2. Follow-up 3 din pore, Last follow-up 7 din pore. Beshirbhag reply ase follow-up theke.
  3. Reply dile Client report khulun, Save as PDF korun, "Send report" email er sathe attach kore pathan.
  4. Call e report ta dekhiye recommended package ta bolun. Guarantee thakle bolun.
