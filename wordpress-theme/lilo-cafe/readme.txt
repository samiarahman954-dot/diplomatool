=== Lilo Cafe ===
Requires at least: 6.0
Tested up to: 6.8
Requires PHP: 7.4
License: GPLv2 or later

Elementor-ready cafe theme built from the Lilo Cafe design.

== Installation ==
1. Appearance > Themes > Add New > Upload Theme > lilo-cafe.zip > Activate.
2. Appearance > Lilo Demo Import > Import demo.
   The importer installs/activates Elementor, imports the images, builds the
   Home and Menu pages, the Elementor header and footer, the navigation menu,
   logo and homepage setting.

== Editing ==
* Pages: Pages > Home / Menu > Edit with Elementor. Every section is a
  "Lilo ..." widget (panel category "Lilo Cafe") with Content and Style tabs.
* Header / footer: Appearance > Header & Footer > Site Header / Site Footer >
  Edit with Elementor. Choose which template is used in
  Appearance > Customize > Lilo Cafe Theme. Elementor Pro Theme Builder
  headers/footers also work and take priority.
* Brand colors, sticky header, fallback footer text and social links:
  Appearance > Customize > Lilo Cafe Theme.
* Links can use {home} (site address) and {menu} (Menu page), e.g. {menu}#ice.

== Widgets ==
Site Header, Site Footer, Hero (arch split / full-bleed, live open status),
Menu Categories, Signature Price List, Product Showcase, Our Story, Mission
Quote, Visit / Hours & Map, Merch / Tag Pills, Social Feed, Page Header,
Menu Tabs (sticky, scroll-spy), Menu: Price List, Menu: Photo Cards,
Menu: Options & Add-ons, Small Note.
