# Lilo Cafe — WordPress theme (Elementor)

Lilo Cafe mockup (`Home` + `Menu` page) theke banano complete WordPress theme.
Install korar file: **`lilo-cafe.zip`**. Source: `lilo-cafe/`.

## Install (one click)

1. WordPress admin → **Appearance → Themes → Add New → Upload Theme** → `lilo-cafe.zip` → **Activate**
2. **Appearance → Lilo Demo Import** → **Import demo**

Importer nije nije kore:

- Elementor plugin install + activate kore (already thakle skip)
- Logo, hibiscus, 20 ta product image ar demo photo Media Library te import kore
- **Home** ar **Menu** page Elementor diye build kore, Home ke homepage set kore
- Elementor e edit kora jay emon **Site Header** ar **Site Footer** template banay
- Navigation menu, site logo, site icon, title ("Lilo Cafe · Jasper, GA") set kore

Abar import dile duplicate hoy na; demo page gulo reset hoy, onno page e haat dey na.

## Customize

| Ki | Kothay |
|---|---|
| Je kono section er text, image, link, color, font, padding | Page → **Edit with Elementor** → section e click → Content / Style tab |
| Header / footer | **Appearance → Header & Footer** → Edit with Elementor |
| Brand color, sticky header | **Appearance → Customize → Lilo Cafe Theme** |
| Notun section add | Elementor panel e **"Lilo Cafe"** category theke drag |

Link e `{home}` (site address) ar `{menu}` (Menu page) use kora jay, jemon `{menu}#ice`.

## Elementor widgets (17 ta)

Site Header · Site Footer · Hero (Arch split / Full-bleed, live "Open now" status) ·
Menu Categories · Signature Price List · Product Showcase · Our Story ·
Mission Quote · Visit / Hours & Map · Merch / Tag Pills · Social Feed ·
Page Header · Menu Tabs (sticky + scroll-spy) · Menu: Price List ·
Menu: Photo Cards · Menu: Options & Add-ons · Small Note

Protiti widget er Style tab e section background, padding, max width, border,
protita text er color + typography, button er normal/hover color, grid er card
width/gap, image frame radius/height ache.

## Notes

- Hero status (Open now / Today …) er shomoy **Settings → General → Timezone** onujayi hisab hoy; ghonta Hero widget e din onujayi deya jay.
- Demo photo gulo import er shomoy Unsplash theke download hoy. Server Unsplash e connect korte na parle bundled image use hoy — pore Elementor e nijer chhobi diye replace korun.
- Menu tabs sticky thakar jonno Menu Tabs widget ar menu section widget gulo ekoi container e rakhte hobe (demo te already evabe ache).
- Elementor Pro thakle Theme Builder er header/footer o kaj korbe (priority pabe).
